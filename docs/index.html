🖨️ Phomemo M110 Drucker

Web-Interface für Label-Drucker mit präziser Kalibrierung

📁 GitHub 🐍 Python ⚡ Flask 🔵 Bluetooth

✨ Features

🌐 Web-Interface

Benutzerfreundliche Bedienung über jeden Browser

🎯 Y-Offset Kalibrierung

Präzise vertikale Positionierung für perfekte Label

📝 Text & Bilder

Druckt Text und Bilder auf 40×30mm Labels

📏 Segmentierter Volltest

Nutzt komplette 30mm Label-Höhe optimal

⚙️ Hardware-optimiert

Speziell für M110 Hardware-Limits angepasst

🔵 Bluetooth

Stabile Verbindung über rfcomm

🚀 Schnellstart

1. Installation:

pip3 install -r requirements.txt

2. Bluetooth-Verbindung:

sudo rfcomm bind 0 12:7E:5A:E9:E5:22

3. Server starten:

python3 phomemo_server.py

4. Web-Interface öffnen:

http://localhost:8080
📖 Vollständige Anleitung

⚙️ Technische Daten

Spezifikation Wert
Label-Größe 40mm × 30mm
Auflösung 320×240px
Hardware 384px Breite (48mm @ 203 DPI)
Verbindung Bluetooth rfcomm
Segmentierung Max 100px pro Block

🔌 API Endpoints

GET / - Web-Interface
POST /api/print-text - Text drucken
POST /api/print-image - Bild drucken
POST /api/print-calibration - Kalibrierungs-Test
POST /api/print-full-height - Volltest (30mm)
POST /api/save-calibration - Kalibrierung speichern
GET /api/status - Drucker-Status
